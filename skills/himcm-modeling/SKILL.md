# HiMCM mathematical modeling · integration development06

这是下一版隔离开发快照，尚未独立行为验收、整题测量或安装。旧77候选与默认61保持原字节；历史证据仅作来源，不继承成绩。工具通过不证明科学或获奖能力。

把完整题目推进为有数学理由、可复算、能执行的作品。贡献可以是更好的决策、更紧的界、更弱的假设、不可行性证明，或同质量下更便宜的计算。复杂度和新名词不自动增加价值。

## 开始、恢复与完整运行

读完整题面和全部附件，核验目标年份原规则、允许信息与AI披露；区分训练、当年信息重演、现代复盘。保存输入哈希、用户要求、首次实际时钟、原预算/截止、已回答要求和下一动作到PROJECT_CONTEXT.md。恢复读取实际文件和同一代理状态，不重置钟。全权完成请求即连续执行常规可逆步骤，外部提交另需授权。

初始化用 `scripts/init_project.py PROJECT --year YEAR --problem A`。整包自带参考与工具，不依赖另一安装技能。**完整运行先读 [运行合同](references/runtime-contract-r2.md)**，其旧版本介绍与证据日期只是来源历史，以本入口开发状态为准。该合同保留完整的数据版本、逐问覆盖、原规则、独评、来源、PDF与交付要求；不能只读新工作台而跳过这些要求。

## 科学工作台

1. **问题→结构。** 定义状态/动作/信息/目标/约束/单位；每条原要求规定实质输出。用[数学工作台](references/math-workbench.md)找最小可证明结构，走通原始事实/明示偏好到行动的一条决定性链，按需查[模型图谱](references/model-atlas.md)。
2. **基线→构思实验。** 保存独立构思后再看同题作品。用[idea实验室](references/idea-lab.md)和[候选卡](assets/idea-card.md)把少量真正不同的机制变成可检验对象；先造能区分它们的实例，不凑算法数；结构未知影响选择时读[机制判别与实验选择](references/idea-experiment-selection.md)；观测可按结果继续或停止且有可信联合先验时，用[序贯信息与决策](references/adaptive-information.md)比较组合收益、提前停止及相关噪声，未满足前提时保留原问题并换方法。
3. **求解→证据。** 先手算、界、反例和精确小例，再大计算。生成器不得改掉不利评价条件后自称进步。必要时用精确工具，并从不同路径交叉复算。
4. **结果→行动。** 用[决策实验](references/decision-experiments.md)区分拟合提升、行动改善和信息价值。新机制须有公平基线、消融与边界；没有收益时选简单基线。
5. **作品→独评→交付。** 编译前按[构建归档](references/build-archive.md)使用新构建目录，失败稿、源码、日志和原钟全部保留。新运行先读[结构化评审契约](references/structured-review.md)，每轮保留全文报告并生成绑定JSON；必须用`check_gate.py --review-format structured-v1`，不能降级旧格式来获取通过。 逐问实质覆盖、全文文图、关键替代复算、原问题逐项复验、最终PDF和原预算封包均执行。评委全新上下文，只给完整允许输入，支持时fork_turns:none。原上限两FULL加一SHORT，全部等待计入原钟；作者自行等待、返修、复现和封包，不等父级回执。问题FIXED不等于原任务已回答。缺项如实PARTIAL。

有固定截止时，首次保存原钟和SHA；阶段切换及长工具返回执行[阶段截止检查](references/phase-deadline.md)，普通同步命令用其run入口。保留所有实际状态；工具不能抢占模型思考、外部评委或脱离进程组的构建器。披露仅写已发生且可定位的行为，具体停止与披露规则见运行合同。

首次预算可用15%读题基线、15%构思判别、30%求解、40%验证审阅写作封包，按工具实际延迟调整，不延长总钟。一半时间应有全部要求的可用基线。新模型不值得扩展时及时停止。

## 精确工具

数学工具使用Python标准库；构建归档另外执行你选择的构建器，固定HTML页的可选全页预检依赖PyMuPDF，环境依赖单独记录。有限决策、LP、矩界及盒域工具将输入与代码哈希写入结果，`--output`只能新建文件。时间口径工具只输出stdout，另存输入和脚本哈希及原stdout；输出v2逐项区分合法观测目标与未定义代理，读取者检查各项状态，不能只看退出码0。

```bash
python /path/to/skill/scripts/finite_decisions.py input.json --output result.json
python /path/to/skill/scripts/check_linear_certificate.py input.json --output checked.json
```

有限决策工具只分析给定有限纯行动/情景、所有行动在所有情景可行、同量纲损失。给期望/最坏/后悔、有限信号策略与信息价值，不替用户选风险偏好；不处理状态相关可行域、多阶段控制或连续未知分布，情景最大值不冒现实最坏界。

LP检查器只核`min cᵀx, Ax≥b, x≥0`的精确原/对偶证书。零差距认证此LP最优；正差距仅给界。整数、非线性、近似误差界及现实模型有效性另核；重述不能偷删约束。

需跨整个允许模型类证明范围、处理连续不确定参数或时间聚合时，按需读[有证据的数学工具](references/certified-math-tools.md)：`moment_bounds.py`给单调积分／一阶矩紧界及证书；`affine_box_decisions.py`给有限行动仿射损失在整个盒域的最坏后悔见证；`temporal_state.py`核有限观测时点的存量累积与非线性平均。先证明适用条件；更一般问题保留原建模自由，不为套工具改变原题。

工具均不认证数据真实性、贴题性、科学贡献或作品完整。未证明结论保留限定。
