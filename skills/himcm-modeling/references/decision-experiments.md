# 检验模型是否改善行动

明确何时知道什么。找哪个输入变化改变动作；不变时区分机制无效、约束饱和、并列或未覆盖翻转点。解析阈值优先于任意百分比扰动；数值搜索明确范围/分辨率。

分开数据、参数、结构、偏好、随机运行误差。无概率依据就报情景/区间，不自动等概率。等价拟合模型可能推荐不同或相同，前者需新信息/稳健方案，后者仍可有条件行动。

原题目标、比较代理与误差保证逐项核适用域。例如观测状态全部合法，但“把年末增量加到平均基线”可能超出已知曲线；这时保留原观测目标，将该代理及依赖它的差值/界标为无定义。不能外推、裁剪或填0，也不能将“对照无定义”报成数值收益或无限提升。若原题确实要求超出已知范围的预测，该要求仍缺证据，不能用一项局部可计算结果宣布整题完成。

## 有限决策与信息价值

`scripts/finite_decisions.py`只用于固定有限纯动作/情景、所有动作在所有情景可行、同量纲损失。结论以给定集合为条件；概率/信号准确度真实性另证。遗漏动作、错误损失表不由脚本自动发现。

```json
{"schema_version":1,"actions":["A","B"],"states":["dry","wet"],
 "all_actions_feasible_in_all_states":true,"losses":[[1,9],[5,3]],
 "probabilities":["1/2","1/2"],
 "signals":{"names":["low","high"],"conditional_on_state":[["4/5","1/5"],["1/5","4/5"]],"cost":"1/2"}}
```

losses行=动作/列=情景；条件概率行=情景/列=信号。无概率只报最坏损失/后悔与非支配动作，期望/信号分析为空。概率与条件行精确和为1，不自动归一化。信号须在动作前到达，之后信息不能部署为条件策略。

损失L(a,s)，情景最优m_s=min_a L(a,s)。报告期望、max_s L及max_s(L−m_s)，保留所有并列；风险偏好由原题/决策者定义。max只覆盖所列情景。

有先验p：V0=min_a Σp_sL(a,s)，Vperfect=Σp_sm_s，EVPI=V0−Vperfect是该假设下完全信息价值上限。有限信号z：Vsignal=Σ_z min_a Σ_s p_sP(z|s)L(a,s)，EVSI=V0−Vsignal。EVSI超过同量纲观测成本才有期望净收益。若成本改变可行域/后续动作，重建模型，不能只加常数。

机制当前观测等价时找能区分它们的观测；行动本来相同则不采无决策收益信息。完全预见只作理论界。

移除新机制，保持其余信息/预算/约束，复算行动与原始损失；给事前提出的失效/无增益场景。模型与算力同时改只报告联合效果。最终给执行者、动作、成本、范围、翻转、回退并引用当前结果。基线胜出就选基线。

涉及随机策略、多先验或信息时序的最优性主张时，按需读[保持决策问题与工具对应](decision-contract.md)，先核策略权限与原题约束，再比较工具结果。
