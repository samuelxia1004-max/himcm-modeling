# HiMCM mathematical modeling · v8.4-r2 candidate

把完整题面和附件推进为数学合理、逐问有实质答案、可复算且易读的英文作品。以 O/F 作品作参照；内部质量分、机械检查和官方奖项分别报告。此文件为继承的完整运行合同，当前开发状态与证据以顶层SKILL.md为准。历史验证不认证新快照。

## 开始、恢复与权限

全权完成或继续的请求即授权连续构思、计算、修复和交付，不逐步询问。先读完整原题和全部官方附件，确认赛前训练、旧题复盘或当届比赛。初始化或恢复：

```bash
python /path/to/himcm-modeling/scripts/init_project.py PROJECT --year YEAR --problem A
```

`PROJECT_CONTEXT.md` 记录题目/输入版本、总预算和截止时点、已完成的实质答案、当前结果、待解决问题及下一动作。项目相对路径和 SHA-256 绑定输入、模型、参数、代码、结果、文稿、评审。只在项目及其 scratch 内生成文件；不删除既有资料，修订与归档保留版本。外部提交另需用户授权。

## 时间内形成完整作品

开始时按风险分配预算，预留至少最后四分之一用于验证、写作和最终核查。约一半时间应已有全部子问的稿件骨架与可用基线；约四分之三时运行第一次交付检查。扩展模型必须具体修复基线失败或回答额外必答任务，否则优先完成基线的证据链。

独立评审默认最多两次完整审阅加一次最终短复验，均计入原预算。第一轮优先核查影响主要答案的错误；第二轮核查修复及当前全文；最终短复验也必须另开全新上下文，逐项确认原问题和最终 PDF 哈希；不能延续前轮评审会话后声明 fresh_session: yes。阻塞问题仍在时，修复或收缩/撤回对应结论并复验该处置。处置通过后，重新判断对应原题要求：补出缺失答案、给出覆盖原问题的不可行性论证，或保留该任务 PARTIAL；不能用问题条目的 FIXED 代替任务完成。时间不足则交付明确的 PARTIAL。达到轮数上限不自动关闭问题。不要为了固定页数、模型数或审稿意见数量无限扩写。

有固定截止时按[阶段截止检查](phase-deadline.md)保存原钟哈希并运行可执行检查；普通同步命令受run入口约束，嵌套构建和外部评委另按该文边界管理。在写作/编译、派发或等待评委、返修、复现、封包这些阶段开始前读取实际UTC；长计算或工具返回后再核一次。把观察点写到项目时钟账本，保留最初截止。若已过截止，停止新增科学工作和评委派发，只保全已有产物、实际失败与缺项，交付PARTIAL；不要先补做完整流程再把最后一次读钟称为截止时刻。运行间隔原因未知时保持未知。阶段检查只能发现过时，不能保证平台不中断或把等待从预算扣除。

## 解题主线

1. **逐问合同与选题。** 每条要求写成对象、输入、输出、成功标准、约束、验证方法和论文位置，登记 `artifacts/gate.json` 的 requirements。涉及条件、偏好或外部状态的必答功能，追踪输入如何进入规则、约束和可行动输出，并用有判别力的输入变化检查该路径。最优区间、约束饱和等可合理导致输出不变，但须说明；固定默认值的示例不代替文稿承诺的可配置功能。按数据可得性、可解释性、可完成性及验证机会比较 A/B，选择能闭环全部任务的路线。读 [problem-to-model.md](problem-to-model.md)。
2. **独立构思。** 看同题作品之前保存 `artifacts/independent_ideas.md`。从守恒、尺度、空间、时间链、随机性、排序和资源结构寻找自然表示；先构造最便宜的基线。路线有实际选择时，展开足以代表关键结构差异的少量候选，给公式骨架、必要数据、能改变选择的判别测试及失败条件；有唯一自然解析结构时说明理由，不凑模型。GA/PSO 等不同求解器不算不同机制。选出能闭合任务且数据支持的主线。按需读 [award-thinking.md](award-thinking.md)、[model-atlas.md](model-atlas.md)。
3. **原始数据到决策。** 按 [data-analysis-playbook.md](data-analysis-playbook.md) 执行原始版本→实体/单位/时空口径/缺失审计→探索→处理→计算→验证→决策。题给地图和表格必须实质使用；核对下载内容真实类型，保留转换、误差和新分母。来源日志用唯一ID和精确Dataset名称标识数据集；外部检验的source_ids逐一对应该ID，data_source与其Dataset名称完全一致，不能靠“city/年份”等词重合认定同一数据。每个重要参数标 observed / attachment / external / estimated / assumed，记录数值、范围、用途、来源、访问日期和适用时段。不能用合成数据冒充附件或实测。
   在投入大批仿真或优化前，实际重建一条能改变建议的 `原始事实或明示价值判断→变换→模型输入→决策`。观测输入有来源、单位和口径；规范输入有定义、理由及代表谁的偏好，不假称专家测量。只有假设评分时，选择可支持的主张、条件方案或待区分集合；重复扰动不能补足现实证据。细则见上述参考§4。
4. **数学合同与求解。** 固定变量、单位、可用信息、目标/并列规则、硬约束、假设及理由、评价器、误差精度和停止条件。先手算/解析小例，再基线和主求解。优化输出独立复算可行性与目标；化简须保留全部声称的目标与合法边界。随机方法报告重复波动；含重尾或非线性风险的期望目标先检查必要矩存在性，有限次模拟不能证明期望有限。涉及未来输入、排队、地图拓扑、服务事件、尾部风险或分母转换时按需读[合同扩展](model-contract-extensions.md)。排名/准入、服务链或比较读 [decision-contracts.md](decision-contracts.md)。主要结果的决定性输入、公式、参数/随机生成器和中间量应能从比赛允许的报告内容回查，不能只指向未提交代码。
5. **按主张验证。** 摘要主张登记 claims，事前为各主张登记能推翻它的检验。预测/经验效应用未参与拟合、阈值、权重和选择的真实数据，并与相同信息、样本、约束、时窗和预算的朴素基线比较；看过结果再改规则，该数据即为开发集。`external_check` 改名不能恢复独立性。优化用独立计算、精确小例/界与现行或简单策略对照；机理、规范和偏好主张检查量纲、守恒、极限、反例及决策翻转点。没有独立数据就明确收缩为未经实证的条件结论，在正文给出限定摘录。失败检验须修复后用新证据检验、收缩范围或撤回；模型输给基线应如实说明，选基线或解释新增回答。计数/年度总量不替代时长/极端风险。读 [validation-review.md](validation-review.md)。
6. **解释与实施。** 从数值推出具体选择、成立范围、翻转阈值和回退方案。按题意说明执行者、时间、成本、资源约束、风险、利益相关方、公平性与监测更新；不适用项简述理由。因子敏感不等于可控或值得优先干预。

## 年份、来源和学习库

开始时核验当届 COMAP 原题、Instructions 和 AI Policy；[contest-rules.md](contest-rules.md) 的快照需刷新。不把继承文件中的某年规则当当前事实；总页数、字号、AI报告计页、匿名、队号/页码和文件大小以目标年份实际官方原文为准。没有官方18页下限，18–25页仅是深度诊断参考；完整短文按实质评审，不以填页替代证据。参考/附录是否计页按目标年份的规则和明确锚点，不臆造豁免。 `pdf.main_pages` 仅表示 AI 报告前正文页数，不等于当年计入上限的页数。默认把 AI 页计入；只有目标年份原文明确豁免时，才登记 `rules.ai_report_excluded_from_main_limit: true` 及 `rules.ai_report_exclusion_rule_quote`，并实际核对物理总页数、正文页数和计入页数。

历史训练先明确是“当年信息重演”还是“现代资料复盘”。前者输入/校准/验证限截至比赛时已可得的资料，分别保存原始发布日期、数据覆盖期、所用修订版和访问日期；版本核查读 [source-version-check.md](source-version-check.md)，检查 PDF 原文修订说明并逐字段对照实际使用内容；metadata 和目录名中的年份仅为线索，不能证明该版在历史赛期可得；确切截止日未知则记录不确定范围，不把1月1日当真实赛期。后者允许现代资料但明确其角色，不把结果冒称当年可实现表现。比赛期间遵守禁止队外人类协助、调查访谈及公开传播赛题/方案的规则，真实披露 AI。

学习库包括本机技能整合、Nature 方法链和 O/F 作品经验，按机制查阅，非必引清单。只摘要阅读的文献不能支持具体方法或定量断言。参考 [source-integration.md](source-integration.md)、[nature-method-transfer.md](nature-method-transfer.md)、[o-paper-practices.md](o-paper-practices.md)；v6结构建议 [o-paper-practices-v6.md](o-paper-practices-v6.md) 按任务触发。新地区迁移、流程图、耦合、区间等只有实质用途才增加。

## 论文、独立评审与交付

按“任务→假设与理由→数学定义→数据→求解→结果→验证→决策”组织；Summary Sheet 最后写且完整落在第一页，含核心选择、重要数字/单位、验证结果和建议。信函/文章按原题受众完成。图表、主文、摘要和非技术建议共享当前结果证书。自然英文终审整合 academic-humanization、humanizer、stop-slop、anti-defensive-writing、no-negative-echo、humanize：冻结数学事实、术语、数字、单位、引用和真实限定，删除空话重复，编辑后核对科学语义。细则见 [paper-and-style.md](paper-and-style.md)。

评审用全新上下文，给原题、全部附件、当前 PDF 及所需复算证据；后续加原问题表。可用 Codex 新会话或独立子代理；平台支持时显式禁用历史继承（本工具为 `fork_turns: none`），只传允许输入。新代理ID本身不证明隔离，延续会话不算fresh。记录实际派发设置、模型、会话、阅读/看图范围、复算和输入哈希；不能把自写记录当独立性证明。只列真实问题，不设“五条意见”配额。每项有稳定编号、位置、证据、Severity、影响、最小修复、当前状态和复验条件。最终审阅须针对实际最终 PDF，对所有已有编号重新给 verdict；短验也逐ID确认，不能用全局结论代替。

新项目直接执行[结构化评审契约](structured-review.md)：完整报告先完成，再由该评委写绑定原PDF、任务合同与科学文件的JSON记录；完整性与问题闭环分别判断，所有旧记录和稳定ID保留。使用`check_gate.py --review-format structured-v1`，不得用旧格式通过代替新接口验收。仅维护既有旧格式项目时才读取`assets/critic_prompt_template.md`、`assets/critic_template.md`的LEGACY部分；新项目不套用其中的原始Markdown字段协议。

```bash
python /path/to/himcm-modeling/scripts/check_gate.py PROJECT --pdf final/TEAM.pdf --review-format structured-v1 --output PROJECT/artifacts/review/gate_result.json
python /path/to/himcm-modeling/scripts/check_pdf.py PROJECT/final/TEAM.pdf --team TEAM --main-pages N --max-main-pages CAP
```

GATE_PASS 仅说明已登记证据的机械一致性，不能单独判定论文完成、数学正确或获奖。GATE_FAIL/INCOMPLETE 保留缺口；还须逐问实质复核、关键数值替代路径复算、最终PDF全页实际查看、格式/匿名与真实AI披露检查。AI核查实际定位正文使用处、参考文献条目与追加报告，按目标年份原文判断，不能只见到报告标题就算完整，也不把政策示例升级为未写明的硬性要求。只有这些实际执行且核心阻塞均闭环，才能称科学交付完成。缺失输入、检验、最终渲染或核心修复则准确标 PARTIAL，并保存仍有价值的成果。

每次用于观察排版或交给评委的编译，执行[构建归档](build-archive.md)。归档核对与科学评审分别进行；`check_gate.py`没有自动证明所有失败构建都保留，人工核对构建账本及原始文件，缺口保留PARTIAL。

AI报告与完成度文字按该稿冻结前的实际行为写。对阅读、视觉检查、独评、返修和干净复现，先找真实产物及其范围，再用已完成时态；模板、空review_index、渲染出的页面图片或计划中的命令不构成完成证据。尚未做的步骤写待完成，不能先预写“已检查/已评审/已复现”，期待后来补齐。报告引用的复现说明与支持文件先核实存在、路径正确且能执行。最终核对正文披露、状态文件与实际记录相互一致，冲突本身就是待修问题。

一份PDF不能在冻结前拥有针对其自身最终字节的后续独评回执。正文准确披露截至本稿已完成的工作和此前实际审阅范围；针对本稿最终字节的审阅、gate与封包回执在外部支持记录绑定，不为插入“本稿已获最终审阅”而改动已审PDF形成循环。真实科学修订仍按原轮次上限重新审阅。截止后发现的错误声明另存更正和原稿，不能静默改写原稿或补记已发生。

交付英文PDF、可编辑稿、本地代码/数据、来源/引用账本、结果证书、图表源码、评审/修复记录和复现说明；比赛实际提交按规则，内部支持包单独保存。

## 0–1评分与持续改进

用户要求评估水平或改进技能时，读 [evaluation-protocol.md](evaluation-protocol.md)。从真实失效提炼通用修复，冻结版本后独立前向验证；训练/开发/测试题、首稿/辅助返修、完整整题/构思探针分开。学习过解答的旧题不能重新标为从未见过；清理参考文件只能去除显性泄漏，不能清除模型预训练记忆。

0–1分呈现当前作品的证据质量，附样本、逐项证据和未核查范围；官方O/F只用可核验标签作参照，不给“必获O”或虚构获奖概率。均值达到0.98不自动叫稳定；报告最低分、逐题分布、重复运行和跨评委差异，保留失败。复杂修订用冻结技能、原题和附件在独立新上下文完整求解，再从原始输入核验。


代理状态核验只查询自己的具体句柄或自己任务路径前缀。不要为查容量列出整个代理树，避免接收同题其他作者/评委结果；若工具仍意外暴露，保存原事件并如实限定隔离声明，不能声称严格零暴露。此观察规则不修复外部等待延迟，不改变原钟。
