# 来源版次与历史可得性核查

当来源用于历史信息重演、校准或验证时，在来源日志旁保存以下可回查证据。现代资料复盘也记录所用版次，避免同名网页或 PDF 更新后改变含义。

- 原始发布：记录机构、标题、原始发布日期及支持该日期的原文位置或档案；区分首次发布与网页更新时间。
- 覆盖期：逐项登记数据对应的起止时间、口径、地区、单位及适用人群；覆盖到某年不等于该文件于该年已发布。
- 使用版本：保存实际下载原文及 SHA-256、修订版标记、修订日期与访问日期。直接阅读 PDF 的版权页、前言、修订说明、脚注或版本历史；搜索结果与 PDF metadata 仅用来定位证据。
- 精确字段对照：记录报告使用的变量、数值、公式或机制所在页/表/字段，与所用原文逐项核对。修订版若改变定义、分母或建议，说明对模型输入、校准、验证与结论的影响。
- 历史可得性：以所用具体版本的公开证据对照真实赛期截止时点。无法证实该版当时可得，标 UNKNOWN；寻找当时版本，或将其限定为现代复盘/背景。目录名年份、URL 年份、文件创建时间及数据覆盖年份都不能单独证明历史可得性。

证据不足时记录缺口和结论范围，不编造发布日期、修订历史或外部内容。核查记录是来源审计材料；机械 gate 的日期或字段通过不能证明来源真实、版次相同或历史可得。
