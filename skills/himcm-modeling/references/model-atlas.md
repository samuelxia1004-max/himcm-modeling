# HiMCM 模型选择与失效检查

这些是针对任务的候选结构与本地验证建议。根据题面建立独立构思后再使用；题号和奖项不决定算法。文献学习卡提供外部模型的条件与来源，下面的迁移关系属于建模建议。

| 任务结构 | 最小模型 | 何时扩展 | 关键反证 |
|---|---|---|---|
| 资源随时间储存、消耗 | 存量守恒与容量约束 | 损耗、价格时变、跨时决策影响结论 | 能量守恒、极端负荷、容量/效率边界 |
| 房间/设施/路网中的任务 | 带服务时长的图与路线分配 | 拥堵、阻断、优先任务、多人协作 | 覆盖、连续性、并发、最终撤出 |
| 总足迹与跨方案比较 | 活动量乘因子，分项核算 | 生命周期、间接影响、未来结构改变 | 双重计算、系统边界、时空口径 |
| 生长、传播、种群变化 | 差分方程或常微分方程 | 空间异质性、个体差异、互动机制 | 初值、非负、守恒、极限、参数可辨识 |
| 拥堵、服务与等待 | 流量守恒与排队/事件仿真 | 多服务器、优先级、到达时变 | 到达率超过容量、等待/服务混淆 |
| 决策、排序、选址 | 可解释的加权效用或覆盖/预算模型 | 价值冲突、相关指标、空间覆盖 | 权重翻转、排名反转、非支配解 |
| 时间预测与趋势 | 最近值、季节均值、简单回归 | 留出样本证明需要升级 | 时间泄漏、结构变化、外推、预测区间 |
| 参数反演与模型比较 | 最小可辨识参数模型 | 多来源数据、状态不可观测 | 等价参数、残差结构、过拟合 |


从时段 t 的能量平衡写起：

`E[t+1] = E[t] + η_charge P_charge[t] Δt − P_discharge[t] Δt / η_discharge`。

统一能量和功率单位；容量约束 `0 ≤ E[t] ≤ C`；负荷由发电、放电、外购与允许的缺电共同满足。定义初始/终止电量、充放电互斥、功率上限和可接受缺电。容量 C 与电池数量的离散关系、初始成本、维护、寿命和折现来自数据或明确假设。终止电量自由会产生“借走最后一时段电量”的假优势。小规模枚举或线性规划核对。

日均耗电低不证明任一时间段可行。

## 疏散、搜查与调度

图的边代表可行移动，边成本可包含时间；节点搜查/救援另计。区分访问全部房间、确认搜查、帮助人员撤出和完成返回。若目标是全部任务完成时间，通常涉及人员完成时刻的最大值，不能直接用所有人的工作时长总和替代。

使用贪心分配作基线，解释优先级和路线规则；精确模型可从小规模枚举、指派、整数规划或动态规划开始。时间变化和随机堵塞需要重规划或事件仿真。任何“最短路径”结论都应明确其覆盖、服务、容量与安全约束。重访是否增加可靠性取决于独立检测假设，不能直接把两次检测错误率相乘而省略相关性。

## 环境足迹、赛事、城市与高性能计算

先定义功能单位，例如每场活动、每位参与者、一次计算任务或一年服务；再定义直接/间接、建设/运营/报废、旅行与采购边界。排放量用活动量与对应地区/年份因子相乘；不同温室气体折算统一时间尺度。能源需求、耗水、废弃物和排放可存在重叠，综合评分前检查重复指标。

跨年比较同时受规模、技术、能源结构影响，需说明同口径调整；首次举办城市可用可核验代理或情景区间。未来建议写成“若某条件成立，则采用某方案”，以参数区间、情景和权重翻转阈值支撑。评分模型把价值判断显式化；统计方差或熵权反映数据区分度，其数值不自动等于政策重要性。

## 种群、生态与扩散

从过程决定状态：种子、幼体、成体、休眠/死亡阶段可以形成阶段差分模型；空间传播可使用迁移矩阵、扩散核或个体仿真。简单 logistic 模型 `dN/dt = r N (1−N/K)` 是对照，不是每种传播的默认真理。季节性、生境差异和密度竞争分别对应机制。

检查时间步长收敛、边界处理、出生/死亡概率范围、负数与容量、种子离开区域后是否继续追踪。Lotka–Volterra 需要互动关系和参数证据；个体仿真需要比较多次运行的波动，并识别哪些状态影响决策。没有野外观测时，参数与结构敏感性支持条件化结论，不能宣称实证预测准确度。

## 多指标评价与资源分配

定义受益者、成本、效用、约束和公平标准。指标先统一方向与尺度，说明权重来源，再比较加权效用、Pareto 非支配方案或带预算的优化。AHP 一致性检查只检查判断结构，不能证明权重事实正确；不同排序方法相近不替代外部验证。

预算是跨期累计还是每期、人员是一次性还是可复用、设施可否分阶段启用，都应写进约束。以等权、单目标或简单优先级为基线；用权重/预算变化、替代标准化和新增无竞争力方案检查决策稳定性。保留价值冲突，不把伦理偏好包装成数据发现。

## 预测、反演与不确定性

按实际部署时间切分数据；训练数据确定填补、标准化、特征选择和超参数。报告绝对误差与基线差异、区间或重复运行波动。短序列和结构突变限制外推；复杂模型升级需要样本外证据。

反演模型先检查“多个参数组合能否解释同一观察”。不可辨识时减少参数、加入额外可核验数据，或报告参数区间。把参数不确定性、模型结构不确定性、数据误差和随机仿真波动分开。针对最能改变推荐的来源设计验证，不用漂亮的拟合曲线代替它。

同样能拟合数据的参数组合，还要比较是否产生同一推荐。如果等价拟合给出不同决策，报告可能的方案集合、切换条件及需要补充的观测。参数可辨识性检查观测能区分什么，决策稳健性检查不确定性怎样改变行动，两者分别提供证据。
