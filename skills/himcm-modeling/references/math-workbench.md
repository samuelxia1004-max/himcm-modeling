# 从结构到可核验数学

先定义题面量，写手算小例。分清外生输入、待估参数、状态、动作、输出；单位与信息时点进入公式。无量纲化后核恢复单位和边界。

|结构|先做什么|扩展前证据|
|---|---|---|
|资源/路径/有限选择|合法基线、枚举小例、容量/割/松弛界|独立核约束与目标，大例最优需界|
|线性/凸结构|标准形、凸性/等价变换、原对偶可行性|有效界夹住最优，不只看solver success|
|动态系统|守恒/非负、平衡、稳定性、极限与尺度|离散误差与范围，模型误差另检|
|预测|信息截止、朴素基线、时序划分、决策损失|选模用过数据不算独立检验|
|反演|保持观测不变的参数变换/等价族|等价参数是否导致不同建议|
|规范性评价|效用、受益者、权重、Pareto前沿|价值取舍/翻转点，偏好不冒观测|
|随机/仿真|分布依据、必要矩、生成过程、误差精度|重复运行不补现实验证|

独立路径如事件模拟对时间线、动态规划对小例枚举、积分对解析边界/步长收敛、优化对原变量约束/对偶界。第二程序复制同一错公式只说明实现一致。复算从原输入出发。

反演、稀疏观测或多个等价拟合机制影响建议时，按需读[目标可辨识性与行动](identification-and-decision.md)：先界住原题目标和行动损失差，再决定需要辨识什么或测量什么。

## LP精确证书

支持`min cᵀx, Ax≥b, x≥0`，对偶`max bᵀy, Aᵀy≤c, y≥0`。两者可行则`bᵀy ≤ optimum ≤ cᵀx`；gap=0证明此LP全局最优，正gap仅给界。弱对偶依据：[Boyd/Vandenberghe讲义，第5章](https://web.stanford.edu/~boyd/cvxbook/bv_cvxslides.pdf)。标准形程序为本项目实现。

```json
{"kind":"min_cx_Ax_ge_b_x_ge_0","A":[[1,1]],"b":[1],"c":[1,2],"x":[1,0],"y":[1]}
```

`scripts/check_linear_certificate.py`接受整数、十进制、分数字符串如`"1/3"`，Fraction精确计算。浮点solver输出不能严格满足则失败，不偷加容差；近似证书需自行给误差界或修成严格可行点。非法输入退出2，不合法证书退出1，有效界退出0；看optimal区分零/正gap。工具不求解LP。

整数问题可用LP松弛下界，但另证整数可行和上下界相等；工具不认证整数问题。非线性/等式/有符号变量需合法重述并证等价，不能偷删约束；未知字段拒绝。

紧界已证就停止无收益搜索，还有gap就报告。差异与数值/抽样/数据误差比较。不能证最优则报预算内最好及有效边界。有限网格无解不能推出一般不可能。
